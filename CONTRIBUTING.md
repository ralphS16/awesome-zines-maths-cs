# Contributing

## Add a zine (pull request)

- Fork this repository and create a new branch for your change.
- Add an entry in `README.md` containing the following information, using the same format as the existing rows in the tables.
  - Title with a hyperlink to where the zine was originally shared/hosted
  - Authors (use hyperlinks when possible)
  - Institution (optional; include it when available)
  - Language (for multiple versions of the same zine, keep one entry and list the different languages with hyperlinks in the `Language` column)

    ```md
    | [**Zine Title**](url) | [Author Name(s)](url) @ [Institution](url) | Language, [Other Language](url) |
    ```

- Put this entry into the table corresponding to its subject (pick one from the lists in `README.md`) and keep the table sorted by author(s) then title.
- Open a pull request with a short description.
